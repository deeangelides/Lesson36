# Lesson 36 — Keith Haring: The Artist of the Subway ❤️

Playful-Detective teaching pack for a one-hour online English lesson (Grade 4/5): an information text about Keith Haring, then **oxymorons**, a **figures of speech review** and **prepositions**.

**Open `index.html`**, or publish this folder with GitHub Pages.

| File | What it is |
| --- | --- |
| `index.html` | Home page linking the lesson and all four games |
| `lesson-36-keith-haring.html` | The 27-slide lesson (arrow keys, thumbnail rail, ⛶ Present, print to PDF) |
| `pop-shop-catch.html` | Catch hearts, chalk and badges; dodge sponges and rain clouds. 3 lives (gentle pace) |
| `whack-a-heart.html` | 60-second whack-a-mole with shining hearts. Avoid the grumpy sponge |
| `subway-maze.html` | Random chalk mazes that grow every level |
| `subway-connect-4.html` | Connect 4 against the Barking Dog |

Upload everything (including `haring/`, `stickers/`, `fonts/`, `slides/` and `.nojekyll`). Keep file names exactly as they are.
